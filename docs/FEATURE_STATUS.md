# 主要功能对照（1.8.0）

2026-11-02 对照[参考项目功能介绍](https://github.com/CookSleep/gpt_image_playground#-核心特性)，结合安卓端实际代码检查。本文件列出主要工作流与差距，不表示完整移植上游所有桌面或网页功能。

| 功能 | 安卓端状态 |
| --- | --- |
| 自定义 API、多配置、常见平台预设、模型获取 | 已接入 |
| Images / Responses 生图、流式预览、遮罩 | 已接入，需服务商支持 |
| 16 张相册参考图、画板文字/形状标注 | 已接入；画板导出合并 PNG |
| 视频生成、播放保存、中断后继续查询 | 已接入硅基流动文生/单首帧图生视频 |
| 串行提示词队列、历史、多收藏夹、备份恢复 | 已接入 |
| Agent 多轮对话、分支、上下文图片引用与搜索 | 未接入 |
| fal.ai / sub2api 异步接口 | 未接入；硅基流动视频查询已有独立实现 |
| 自定义 HTTP 供应商 JSON 模板 | 未接入 |
| 画板位置评论、笔画工程保存、遮罩缩放平移 | 未接入；标注画板已支持移动模式下缩放平移 |
| 并发队列、运行中追加任务 | 未接入，当前为串行 |
| 收藏夹排序、默认收藏夹、批量下载原图 | 未接入；现有 ZIP 为作品备份 |
| 本地背景色抠除、外观偏好、配置导入导出 | 未接入 |

1.8.0 本轮补齐标注画板。后续可继续推进异步供应商接入或 Agent 工作流。平台是否兼容仍以具体接口和模型为准。


1.10.0（2026-11-09）：新增 ChatGPT2API 服务商预设和图片专用模式，支持文生图、多参考图及首图遮罩、1–4 张同步 Base64 返回。接入自建服务需要独立部署并配置账号池。未接入其账号池管理、聊天、搜索或自定义流式事件。
