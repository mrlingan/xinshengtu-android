# 1.12.0 验证记录

日期：2026-11-09。版本：1.12.0 / versionCode 24。

## 交付范围

补齐用户内置浏览器打开的[瞬映创作页](https://h3.coolhs.com/studio)中的生成表单：创作页模式切换、文字和图片输入、参考视频、参考音频、首尾帧交换、15/20/30 秒横竖屏模板、视频超分、12 档尺寸及自定义尺寸、8/20 步、补帧开关、服务商进度。

生成页面选择的模式随任务参数保存，不改写已加密保存的配置默认模型。视频和音频先复制到本地缓存，准备任务时校验轨道与时长并复制到任务私有目录。旧模式不接收的素材会显示移除提示，提交前阻止不兼容组合。

## 原始依据与事实边界

直接观察网页控件及 DOM：图片/视频/音频输入；宽高输入范围 256–1440；短边清晰度范围 480–1080；常规 4/6/8 秒、8/20 步及补帧开关。没有点击网页“开始生成”，也没有操作网页中已运行的任务。

文档页一度返回 Cloudflare 504。后续根据已打开页面 DOM 中的脚本地址，读取[官网公开脚本 index-zaF-iawm.js](https://h3.coolhs.com/assets/index-zaF-iawm.js)，核对其内嵌 API 文档、上传适配器和提交处理函数；仅作为静态参考，没有执行下载的脚本。

公开脚本 SHA-256：`a71514b8b53c4aa389d8421acac5de2f87060d632869f04b1567d7cb7f474915`。

- 网页 `submit` 适配器将参考视频、音频映射为 `ref_videos` / `ref_audios`，上传返回值使用 `item.ref`。
- 网页提交处理函数对超分传入 `video` 和 `height`，不传常规视频的 `width`、`seconds`、采样和补帧；应用保持这个请求差异。
- 内嵌 API 文档：视频 MP4/MOV/WebM 上限 100MB，音频上限 40MB，各最多 3 个；原视频 12 秒及以上不开放 1080p。AAC 来自网页文件选择器的显式支持列表。
- 网页尺寸目录包括横屏 832×480、1024×576、1280×736、1344×768；竖屏对调宽高；方形 512、736、960、1440。常规自定义尺寸按 32 的倍数校验。保留旧版应用 `auto` 对应的 1344×768，避免改变已有任务的含义；1280×736 可直接选择。
- 超分自定义清晰度按网页归一化逻辑限制为 16 的倍数或标准 1080p。客户端与上传后服务端的原视频时长均参与 1080p 提交前检查。
- 网页进度函数在服务商没有百分比时会按时间估算。应用仅展示服务商返回的文字和明确百分比，没有复制估算公式。

使用 REA 对公开脚本做静态分析。父 Evidence：`ev_6a1d901bb948149c517c7d387e7a7455ac9096be8eb89b552b7e2d5be1072f41`。分析器完成语法解析但在语义分析阶段触发堆内存限制，图覆盖为 partial；本次具体字段结论来自直接读取的公开脚本文本与已有 API 文档，不依赖完整调用图，不宣称已运行线上接口或穷尽网站全部逻辑。

## 存储、恢复与下载

- `GenerationParams` 增加出片方式、步数、补帧和超分短边清晰度，旧记录默认保持 20 步与补帧开启。
- `ImageTask` 保存音视频相对文件名、原视频时长和服务商进度。缓存路径只存在于创作草稿中，任务准备后替换为相对文件名。
- 复用和重试复制完整输入素材；续查已提交任务跳过重新上传与提交，即使输入文件已经丢失也可下载已有结果。
- ZIP 备份清单升级为版本 3，兼容恢复版本 1/2。音视频文件参与清单、路径检查和大小检查，恢复时验证有效轨道与时长。总备份上限 512MB，单视频输出 256MB、输入视频 100MB、音频 40MB。
- 下载鉴权与跨来源隔离沿用 1.11.0；`download=1` 原生下载入口只对当前任务和同来源发送卡密。配置密钥和私有下载入口不进入 ZIP。
- 上传、提交、查询及下载共用一小时上限；失败不自动重新提交。停止等待仍只取消本地请求。
